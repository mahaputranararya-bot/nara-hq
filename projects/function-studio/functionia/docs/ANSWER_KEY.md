### Practice generators (two worked examples each)

#### Mirror Gate (`MIR-1-…`)

Rule: Reflect (a, b) across y = x → (b, a). a, b in −9…9, a ≠ b.

- ☐ **MIR-1-0035** — A crystal sits at (4, −5). Where does its reflection across the mirror line y = x land? Click the spot on the graph, or type it. (Mirror line: y = x)
  - Answer: **x = −5, y = 4**
  - Working: Swap the coordinates: (4, −5) → (−5, 4). The mirror line y = x is exactly halfway between the two points.
- ☐ **MIR-1-006A** — A crystal sits at (−5, −9). Where does its reflection across the mirror line y = x land? Click the spot on the graph, or type it. (Mirror line: y = x)
  - Answer: **x = −9, y = −5**
  - Working: Swap the coordinates: (−5, −9) → (−9, −5). The mirror line y = x is exactly halfway between the two points.

#### Ghost Scanner (`MIR-2-…`)

Rule: Vertical line test on a pool of graphs: functions (lines, parabolas, cubic, 2ˣ, √x) vs. relations (circles, x = y², x = y² − 2, x = 2).

- ☐ **MIR-2-0035** — A function gives exactly one output y for each input x. Drag the ghost scanner across the graph of y = √x. Is it a function? (y = √x)
  - Answer: **Function**
  - Working: Every vertical line touches y = √x at most once. One input x gives one output y, so it IS a function.
- ☐ **MIR-2-006A** — A function gives exactly one output y for each input x. Drag the ghost scanner across the graph of y = 2x + 1. Is it a function? (y = 2x + 1)
  - Answer: **Function**
  - Working: Every vertical line touches y = 2x + 1 at most once. One input x gives one output y, so it IS a function.

#### Machine Pipes (`MIR-3-…`)

Rule: f(x) = mx + c (m 1…4, c −5…5), g(x) = x² or x + c (c −5…5, not 0), input −4…4; ask f(g(x)) or g(f(x)).

- ☐ **MIR-3-0035** — Ori rolls into the pipes carrying the number 2. Machine g works first, then machine f. What comes out? Find f(g(2)). (f(x) = 3x − 5     g(x) = x²)
  - Answer: **answer = 7**
  - Working: g(2) = 4, then f(4) = 7. So f(g(2)) = 7.
- ☐ **MIR-3-006A** — Ori rolls into the pipes carrying the number −3. Machine g works first, then machine f. What comes out? Find f(g(−3)). (f(x) = x + 4     g(x) = x − 5)
  - Answer: **answer = −4**
  - Working: g(−3) = −8, then f(−8) = −4. So f(g(−3)) = −4.

#### Inverse Bridge (`MIR-4-…`)

Rule: f(x) = mx + c with m in {2, 3, 4, 5}, c in −9…9 (not 0) → f⁻¹(x) = (x − c) ÷ m.

- ☐ **MIR-4-0035** — f(x) = 5x − 8 builds one half of the bridge. Build the other half with the inverse f⁻¹, which undoes f. Fill in the two boxes. (f(x) = 5x − 8)
  - Answer: **first box = −8, second box = 5**
  - Working: f multiplies by 5 then subtracts 8. Undo it backwards: add 8, then divide by 5. So f⁻¹(x) = (x + 8) ÷ 5. Check: f(2) = 2 and f⁻¹(2) = 2.
- ☐ **MIR-4-006A** — f(x) = 5x + 5 builds one half of the bridge. Build the other half with the inverse f⁻¹, which undoes f. Fill in the two boxes. (f(x) = 5x + 5)
  - Answer: **first box = 5, second box = 5**
  - Working: f multiplies by 5 then adds 5. Undo it backwards: subtract 5, then divide by 5. So f⁻¹(x) = (x − 5) ÷ 5. Check: f(2) = 15 and f⁻¹(15) = 2.

#### Domain Fences (`MIR-5-…`)

Rule: Domain and range of √x, x², 2x + 1, 1/x, √(x − 2), −x² + 4, x² − 3, √x + 1 (4 options each).

- ☐ **MIR-5-0035** — Fences mark where f(x) = √(x − 2) is allowed to live. Choose its domain (the inputs x it accepts) and its range (the outputs y it can reach). (f(x) = √(x − 2))
  - Answer: **Domain: x ≥ 2; Range: y ≥ 0**
  - Working: f(x) = √(x − 2): domain x ≥ 2, range y ≥ 0. x − 2 must not be negative, so x ≥ 2. The outputs start at 0 and go up.
- ☐ **MIR-5-006A** — Fences mark where f(x) = √x is allowed to live. Choose its domain (the inputs x it accepts) and its range (the outputs y it can reach). (f(x) = √x)
  - Answer: **Domain: x ≥ 0; Range: y ≥ 0**
  - Working: f(x) = √x: domain x ≥ 0, range y ≥ 0. Square roots of negative numbers have no real answer, so x must be 0 or more. The outputs start at 0 and go up.

### Glitch Shard: Shard of the Two-Faced Mirror

☐ The reflection of y = x² across y = x is x = y². It fails the vertical line test: x = 4 gives y = 2 and y = −2. It only becomes a function if you restrict the domain to x ≥ 0, giving y = √x.

### Practice generators (two worked examples each)

#### Road Builder (`LIN-1-…`)

Rule: Integer m in −4…4 (not 0) or m in {½, −½, 3/2}, integer b in −6…6. Towns are made from the rule (y stays within ±12), so the answer is always clean.

- ☐ **LIN-1-0035** — Build a straight road from town A (3, −5) to town B (6, −8). Set m (the slope, how steep it is) and b (where it crosses the y-axis), then launch Ori. (y = mx + b)
  - Answer: **slope m = −1, b = −2**
  - Working: m = rise ÷ run = −3 ÷ 3 = −1. Then b = −5 − (−1)(3) = −2. So y = −x − 2.
- ☐ **LIN-1-006A** — Build a straight road from town A (−1, 1) to town B (1, −5). Set m (the slope, how steep it is) and b (where it crosses the y-axis), then launch Ori. (y = mx + b)
  - Answer: **slope m = −3, b = −2**
  - Working: m = rise ÷ run = −6 ÷ 2 = −3. Then b = 1 − (−3)(−1) = −2. So y = −3x − 2.

#### Windmill Table (`LIN-2-…`)

Rule: Same slopes and b; four table rows with equal x-steps (step 2 for fractional m).

- ☐ **LIN-2-0035** — The windmill keeps a table of x and y. Find the constant difference to get m, then find b. Build y = mx + b through every row. (y = mx + b)
  - Answer: **slope m = 1, b = −1**
  - Working: y changes by 1 when x changes by 1, so m = 1 ÷ 1 = 1. At x = 0, y = −1, so y = x − 1.
- ☐ **LIN-2-006A** — The windmill keeps a table of x and y. Find the constant difference to get m, then find b. Build y = mx + b through every row. (y = mx + b)
  - Answer: **slope m = −4, b = 5**
  - Working: y changes by −4 when x changes by 1, so m = −4 ÷ 1 = −4. At x = 0, y = 5, so y = −4x + 5.

#### The Merchant (`LIN-3-…`)

Rule: C(s) = rate·s + fee with fee 2…10, rate 1…5, s 1…12.

- ☐ **LIN-3-0035** — The ojek merchant charges a fixed fee of 3 coins, plus 1 coin for every step. How much does a ride of 7 steps cost? (C(s) = s + 3)
  - Answer: **cost = 10**
  - Working: C(7) = 1·7 + 3 = 7 + 3 = 10 coins.
- ☐ **LIN-3-006A** — The ojek merchant charges a fixed fee of 9 coins, plus 1 coin for every step. How much does a ride of 4 steps cost? (C(s) = s + 9)
  - Answer: **cost = 13**
  - Working: C(4) = 1·4 + 9 = 4 + 9 = 13 coins.

#### Budget Ride (`LIN-4-…`)

Rule: Greatest whole s with rate·s + fee ≤ budget (fee 2…10, rate 1…5). Fractional or negative steps break the model.

- ☐ **LIN-4-0035** — You have 12 coins. A ride costs 5 coins plus 2 per step. What is the greatest number of whole steps you can afford? (C(s) = 2s + 5)
  - Answer: **steps = 3**
  - Working: (12 − 5) ÷ 2 = 7/2, rounded down to a whole step. So 3 steps (cost 11 coins).
- ☐ **LIN-4-006A** — You have 24 coins. A ride costs 4 coins plus 4 per step. How many steps can you ride with exactly all your coins? (C(s) = 4s + 4)
  - Answer: **steps = 5**
  - Working: (24 − 4) ÷ 4 = 5. So 5 steps (cost 24 coins).

#### Steepness Check (`LIN-5-…`)

Rule: m = rise ÷ run between two points made from a clean rule.

- ☐ **LIN-5-0035** — A windmill path goes from (0, −2) to (3, 4). What is its slope m? (Slope = rise ÷ run.) (m = (y₂ − y₁) ÷ (x₂ − x₁))
  - Answer: **slope = 2**
  - Working: Rise = 6, run = 3, so m = 6 ÷ 3 = 2.
- ☐ **LIN-5-006A** — A windmill path goes from (−1, −1) to (4, −6). What is its slope m? (Slope = rise ÷ run.) (m = (y₂ − y₁) ÷ (x₂ − x₁))
  - Answer: **slope = −1**
  - Working: Rise = −5, run = 5, so m = −5 ÷ 5 = −1.

### Glitch Shard: Shard of the Endless Wall

☐ A road between (3, 1) and (3, 6) is the vertical line x = 3. Slope = rise ÷ run = 5 ÷ 0, which is undefined, so it can’t be written as y = mx + b, and it isn’t a function.

### Practice generators (two worked examples each)

#### Find the Peak (`PAR-1-…`)

Rule: Read (h, k) from y = a(x − h)² + k, a in {−1, −2, −½, 1, 2}, h −6…6, k −6…9.

- ☐ **PAR-1-0035** — Where is the highest point of this path? Read the vertex (the turning point of the parabola) straight from the equation. (y = −2(x + 6)² − 4)
  - Answer: **vertex x = −6, vertex y = −4**
  - Working: In vertex form y = a(x − h)² + k the vertex is (h, k). Here that is (−6, −4), and the axis of symmetry is x = −6.
- ☐ **PAR-1-006A** — Where is the highest point of this path? Read the vertex (the turning point of the parabola) straight from the equation. (y = −½(x − 5)² − 5)
  - Answer: **vertex x = 5, vertex y = −5**
  - Working: In vertex form y = a(x − h)² + k the vertex is (h, k). Here that is (5, −5), and the axis of symmetry is x = 5.

#### Landing Prediction (`PAR-2-…`)

Rule: Integer roots r₁ < r₂ in 0…12 with an even distance; h = (r₁ + r₂)/2, a in {−1, −2, −½}, k = −a·((r₂ − r₁)/2)² (kept whole).

- ☐ **PAR-2-0035** — The archer’s arrow follows this path. Where does the path touch the ground (y = 0)? Find both roots: they are where it takes off and where it lands. (y = −(x − 1)² + 1)
  - Answer: **first root = 0, second root = 2**
  - Working: Set y = 0: −(x − 1)² + 1 = 0, so (x − 1)² = 1. Then x − 1 = ±1, so x = 0 and x = 2.
- ☐ **PAR-2-006A** — The archer’s arrow follows this path. Where does the path touch the ground (y = 0)? Find both roots: they are where it takes off and where it lands. (y = −2(x − 5)² + 2)
  - Answer: **first root = 4, second root = 6**
  - Working: Set y = 0: −2(x − 5)² + 2 = 0, so (x − 5)² = 1. Then x − 5 = ±1, so x = 4 and x = 6.

#### Symmetry Shot (`PAR-3-…`)

Rule: Other root = 2·axis − root.

- ☐ **PAR-3-0035** — A parabola is symmetric about its axis x = 5. One arrow lands at x = −1. Where does the matching arrow land on the other side? (Axis of symmetry: x = 5)
  - Answer: **other root = 11**
  - Working: x = −1 is 6 away from the axis x = 5. Go 6 the other way: x = 11.
- ☐ **PAR-3-006A** — A parabola is symmetric about its axis x = 2. One arrow lands at x = 4. Where does the matching arrow land on the other side? (Axis of symmetry: x = 2)
  - Answer: **other root = 0**
  - Working: x = 4 is 2 away from the axis x = 2. Go 2 the other way: x = 0.

#### Catapult Launch (`PAR-4-…`)

Rule: Launch r₁, land r₂, peak k → h = (r₁ + r₂)/2, a = −k ÷ ((r₂ − r₁)/2)². a = 0 breaks the model.

- ☐ **PAR-4-0035** — Launch Ori from x = 4 on the ground, over a peak of height 2, to land on the target at x = 6. Set h, k and a in y = a(x − h)² + k. (y = a(x − h)² + k)
  - Answer: **h = 5, k = 2, a = −2**
  - Working: h = (4 + 6) ÷ 2 = 5 and k = 2. Landing: 0 = a(6 − 5)² + 2 = 1a + 2, so a = −2. Path: y = −2(x − 5)² + 2.
- ☐ **PAR-4-006A** — Launch Ori from x = 3 on the ground, over a peak of height 2, to land on the target at x = 5. Set h, k and a in y = a(x − h)² + k. (y = a(x − h)² + k)
  - Answer: **h = 4, k = 2, a = −2**
  - Working: h = (3 + 5) ÷ 2 = 4 and k = 2. Landing: 0 = a(5 − 4)² + 2 = 1a + 2, so a = −2. Path: y = −2(x − 4)² + 2.

#### Hidden Vertex (`PAR-5-…`)

Rule: y = x² + bx + c (b even −8…8, c −6…10) → vertex (−b/2, c − b²/4).

- ☐ **PAR-5-0035** — This path is hiding its vertex in standard form. Complete the square (or use x = −b ÷ 2) to find the vertex. (y = x² − 8x − 3)
  - Answer: **vertex x = 4, vertex y = −19**
  - Working: x² − 8x − 3 = (x − 4)² − 19 (since (b/2)² = 16). So the vertex is (4, −19).
- ☐ **PAR-5-006A** — This path is hiding its vertex in standard form. Complete the square (or use x = −b ÷ 2) to find the vertex. (y = x² + 8x − 6)
  - Answer: **vertex x = −4, vertex y = −22**
  - Working: x² + 8x − 6 = (x + 4)² − 22 (since (b/2)² = 16). So the vertex is (−4, −22).

### Glitch Shard: Shard of the Flat Arrow

☐ Set a = 0 in y = a(x − h)² + k and the x² part disappears, leaving y = k: a flat line, not a parabola. Bonus: y = x² + 1 never touches y = 0, so an arrow on that path never lands. It has no real roots.

### Glitch Shard: Shard of the First Hole

☐ You can’t divide by zero, so x = 0 is not in the domain of y = 1/x. The graph has a vertical asymptote there: a wall it approaches but never touches. (The same is true at x = h for y = a/(x − h) + k.)
