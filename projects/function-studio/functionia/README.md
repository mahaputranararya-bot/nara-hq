# Functionia

**To play:** double-click `index.html` (Chrome or Edge). It works offline, with no install and no sign-up.

A story math game about functions for Grade 10, Term 3, by Group 5 (Nara, Kayyira, Uno) for Mr. Darwin's Function Studio.

- Handover guide: [`docs/README.md`](docs/README.md)
- How to play (and the printable one-page card): [`docs/HOW_TO_PLAY.md`](docs/HOW_TO_PLAY.md), [`docs/how-to-play-card.html`](docs/how-to-play-card.html)
- Answer key for the Math Anchor: [`docs/ANSWER_KEY.md`](docs/ANSWER_KEY.md)
- Rubric self-assessment: [`docs/RUBRIC_SELF_ASSESSMENT.md`](docs/RUBRIC_SELF_ASSESSMENT.md)
- Teacher mode: open `index.html?dev=1`, then Esc → Dev panel
- Tests: `node --test` (from this folder)
